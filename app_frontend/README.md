# MyWay — личный кабинет

Визуальный прототип личного кабинета `mywayis.com` на моковых данных. Все экраны
кликабельны, API не требуется: вместо запросов работает `src/mocks/mockApi.ts`
с искусственной задержкой, чтобы состояния загрузки были настоящими.

## Запуск

```bash
npm install
npm run dev
```

Открыть <http://localhost:5173>.

| Команда              | Что делает                                        |
| -------------------- | ------------------------------------------------- |
| `npm run dev`        | Дев-сервер Vite                                    |
| `npm run build`      | Проверка типов + прод-сборка                       |
| `npm run typecheck`  | Только `tsc --noEmit`                              |
| `npm run lint`       | ESLint                                             |
| `npm run i18n:check` | Сверяет наборы ключей ru/en, падает при расхождении |

## Демо-сценарии

Регистрации в прототипе нет, поэтому состояния переключаются вручную — на
странице входа и в плавающей панели внизу экрана:

| Сценарий             | Состояние                                                             |
| -------------------- | --------------------------------------------------------------------- |
| **Новый пользователь** | Без специальности и интеграций. Запускает онбординг: специальность → приглашение → тур из шести шагов |
| **Free-пользователь**  | WakaTime подключён, участвует в турнире, AI-отчёты закрыты замком      |
| **Pro-пользователь**   | Активная подписка, работающий AI-агент, история платежей               |

Кнопка «Сбросить демо» чистит `localStorage` и возвращает всё в исходное.

На странице входа пароль не проверяется — кроме одного случая: введите `wrong`,
чтобы увидеть состояние ошибки авторизации.

## Что где лежит

```
src/
├── app/           роутер и провайдеры (тема, сессия, онбординг, тосты)
├── styles/        tokens.css — единственный источник цветов и отступов
├── i18n/          инициализация i18next и словари ru/en по неймспейсам
├── shared/ui/     UI-кит: Button, Modal, Table, Chip и остальное
├── shared/lib/    seasons.ts, форматтеры, useChartColors, storage
├── layouts/       AppShell (сайдбар + топбар) и PageHeader
├── features/      доменные блоки: dashboard, integrations, leaderboard, …
├── pages/         тонкие обёртки-роуты, только композиция
└── mocks/         типизированные фикстуры и mockApi
```

Правило: `pages/*` только компонует, логика и вёрстка живут в `features/*`.
Благодаря этому замена `mockApi` на настоящий клиент не затронет экраны.

## Темы и язык

Тёмная тема — продуктовый дефолт, светлая переключается в шапке или в
«Настройки → Внешний вид». Все цвета объявлены в `src/styles/tokens.css`
дважды: в `:root` (тёмная) и в `:root[data-theme='light']`. Новый цвет нужно
добавлять в оба блока, иначе одна из тем поедет.

Recharts принимает строки, а не CSS-переменные, поэтому графики берут цвета
через `useChartColors()` — хук перечитывает токены при смене темы.

Русский заполнен целиком, английский — рабочий каркас. Все строки идут через
`t()`, числа и даты — через `Intl.*`. Русская плюрализация обязательна:
`_one/_few/_many`.

## Сезоны турнира

`src/shared/lib/seasons.ts` — чистые функции, эту же логику потом повторит
бэкенд:

| Сезон  | Границы                                 |
| ------ | --------------------------------------- |
| Зима   | 1 декабря — 28/29 февраля (пересекает год) |
| Весна  | 1 марта — 31 мая                        |
| Лето   | 1 июня — 31 августа                     |
| Осень  | 1 сентября — 30 ноября                  |

`year` сезона — год, в котором он **завершается**: зима 1 дек 2025 — 28 фев 2026
имеет `year = 2026`. Годовой зачёт — четыре сезона, завершившиеся в календарном
году; итоги подводятся 1 декабря. Високосные годы учитываются.

## Чего здесь нет

Регистрации, лендинга и публичных страниц; реальных запросов к FastAPI и

адаптива (прототип рассчитан на ширину от 1280px).
