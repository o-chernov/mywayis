{% translate "Как это работает" %}

{% translate "Что такое WakaTime?" %}
{% blocktranslate %}Это плагин для редактора кода, который автоматически засекает время работы: в каком файле, на каком языке, в каком проекте. Плагины есть для VS Code, всех IDE JetBrains, Vim, Neovim, Sublime, Xcode и десятков других редакторов. Базовый тариф WakaTime бесплатный.{% endblocktranslate %}
{% translate "Можно ли пользоваться MyWay без WakaTime?" %}
{% blocktranslate %}Сейчас нет: WakaTime — единственный источник данных. Мы принципиально не собираем статистику сами, чтобы не ставить вам ещё один агент на машину. Другие интеграции появятся позже.{% endblocktranslate %}
{% translate "Как быстро появятся первые графики?" %}
{% blocktranslate %}Сразу после подключения мы подтягиваем историю за последние 90 дней — это занимает секунды. Дальше данные обновляются автоматически несколько раз в день.{% endblocktranslate %}
{% translate "Что такое теги и зачем их выбирать?" %}
{% blocktranslate %}Тег — это язык, инструмент или своя категория, время по которой вы хотите видеть. Мы предложим набор по вашей специальности, а вы уберёте лишнее и добавите своё. Можно отслеживать и то, что к работе не относится — например, время в играх: оно считается отдельно и в турнир не идёт.{% endblocktranslate %}

{% translate "Данные и приватность" %}

{% translate "Вы видите мой код?" %}
{% blocktranslate %}Нет. Из WakaTime приходят только агрегаты: количество минут, язык, название проекта. Содержимое файлов и их имена в MyWay не передаются и нигде не хранятся.{% endblocktranslate %}
{% translate "Насколько безопасно отдавать вам API-ключ WakaTime?" %}
{% blocktranslate %}Ключ хранится в зашифрованном виде и используется только для чтения статистики. Отозвать его можно в любой момент в настройках WakaTime — тогда мы просто перестанем получать данные. В интерфейсе ключ показывается замаскированным.{% endblocktranslate %}
{% translate "Кто видит мою статистику?" %}
{% blocktranslate %}По умолчанию — только вы. В публичной таблице турнира видны username, специальность и часы за сезон, и то лишь если вы согласились участвовать. Профиль можно закрыть целиком, а город скрыть отдельно.{% endblocktranslate %}
{% translate "Можно удалить аккаунт?" %}
{% blocktranslate %}Да, в настройках личного кабинета. Удаляются профиль, вся статистика и переписки. Действие необратимо, поэтому мы просим подтвердить его вводом username.{% endblocktranslate %}

{% translate "Турнир" %}

{% translate "Обязательно ли участвовать?" %}
{% blocktranslate %}Нет. Турнир — отдельная внутренняя интеграция, она включается и выключается тумблером. Личная аналитика от этого не зависит и работает в любом случае.{% endblocktranslate %}
{% translate "Как устроены сезоны?" %}
{% blocktranslate %}Год делится на четыре сезона по временам года: зима с 1 декабря по конец февраля, весна с 1 марта, лето с 1 июня, осень с 1 сентября по 30 ноября. В конце сезона счётчик обнуляется, результат уходит в историю. Итоги года подводятся 1 декабря по четырём завершившимся сезонам.{% endblocktranslate %}
{% translate "Не победит ли тот, кто просто дольше сидит?" %}
{% blocktranslate %}Часы — не единственная колонка: в таблице видны стрик и изменение позиции за неделю. Регулярность заметна не меньше объёма. И сравнивать себя можно внутри своей специальности, а не со всеми подряд.{% endblocktranslate %}
{% translate "Что если я отключу WakaTime?" %}
{% blocktranslate %}Участие в турнире отключится автоматически: считать часы станет нечем. Уже собранные данные и история сезонов сохранятся.{% endblocktranslate %}
